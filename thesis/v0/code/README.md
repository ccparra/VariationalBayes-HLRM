# Código V0

`analysis/` conserva los análisis exploratorios usados en la tesis original y
`examples/` los antiguos `Run_*.R`. Este código es histórico, parcialmente
interactivo y puede requerir ejecuciones largas; no constituye la interfaz
vigente del proyecto.

La implementación corregida y sus análisis reproducibles están en
`thesis/final/code/`.
